Section 3.1: Abstract Classes
=============================

Instantiate = Create an object from a class.

We do not want to instantiate the parent Product class because we do not know enough information about the product 
(e.g. whether it is physical or digital).

Instead, we only want to instantiate the child classes (PhysicalProduct and DigitalProduct). 
Therefore, the parent Product class must be made abstract (converted into an abstract class) to prevent direct instantiation of the parent Product class.

super()
=============================
super() — used for Calling Parent Methods

super() is used to call the parent version of a method.
However, if the parent version of that method only contains `pass` (no implementation), we do not need to call it using `super()` because there is no behaviour to reuse.
Instead, we can directly implement the method in the child class (method overriding).

Section 4.1: CanBeShipped Interface
=============================
get_fulfilment_info() → The child classes return a message explaining how the product is delivered.
calculate_shipping_cost() → The child class (PhysicalProduct) returns a calculated shipping cost based on its weight, not just a message.

Section 4.2: Single Class and Multiple Inheritance
==================================================

Single Class Inheritance = Child class inherits from ONE regular parent class.
Multiple Class Inheritance = Child class inherits from TWO or MORE regular parent classes (AVOID).

AVOID:
    class PhysicalProduct(Product, ShippingProduct):
        pass
    # Both are regular parent classes.

ALLOWED:
    class PhysicalProduct(Product, CanBeShipped):
        pass
    # Product = Regular parent class
    # CanBeShipped = Interface-style ABC

Note: Python technically considers both multiple inheritance, but the lab allows ONE regular parent class + multiple interfaces.

Section 5: Attributes vs Calculated Values (JSON Saving)
=========================================================

- Attributes = Values stored in an object (e.g. `self.__weight`).
- Calculated Values = Values computed using existing attributes (e.g. `self.__weight * 5`).

JSON Saving:
- Save attributes needed to reconstruct the object.
- No need to save calculated values if they can be recalculated.

Example: Save `weight`, NOT `shipping_cost`, since shipping cost can be recalculated from weight.
